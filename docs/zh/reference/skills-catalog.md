# 技能目录

| Skill | 用途 |
|-------|------|
| `git-workflow` | 以 GitHub Issue 为任务记录；init → 实现 → finish/关闭 |
| `git-worktree` | 用 linked worktree 隔离/并行开发；可与 git-workflow、local-workflow 组合 |
| `local-workflow` | 本地追踪于 `tasks/tracing/`；不需要 GitHub |
| `docmd` | 用捆绑 Diátaxis 模版搭建/构建文档站；本站即活示例（见 `docmd/template/`） |
| `github-cli-skill` | 仓库与 Issue 的精简 `gh` 助手 |
| `gh-create-release` | 创建 GitHub Release |
| `scanning-for-secrets` | Token 模式扫描 + 可选 pre-commit hook |
