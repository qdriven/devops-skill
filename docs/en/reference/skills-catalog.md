# Skills catalog

| Skill | Purpose |
|-------|---------|
| `git-workflow` | GitHub Issue as the task record; init → implement → finish/close |
| `git-worktree` | Linked worktrees for isolated/parallel work; combine with git-workflow or local-workflow |
| `local-workflow` | Local tracing under `tasks/tracing/`; no GitHub required |
| `github-cli-skill` | Short `gh` helpers for repos and issues |
| `gh-create-release` | Create GitHub Releases |
| `scanning-for-secrets` | Token pattern scan + optional pre-commit hook |
