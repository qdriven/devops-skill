# 上手模版

完成本教程后，你将在本机跑起基于本模版的 docmd 站点，并清楚 Diátaxis 各目录的用途。

## 前置条件

- Node.js 18+
- npm

## 步骤

1. 在终端进入本模版目录（`docmd/template`，或复制后的目标目录）。
2. 安装依赖：

   ```bash
   npm install
   ```

3. 启动开发服务器：

   ```bash
   npm run dev
   ```

4. 打开 `http://localhost:3000`，确认首页列出教程、操作指南、解释、参考四类入口。
5. 打开 `docs/zh/tutorials/`，确认本页属于「教程」——面向学习的内容。

你现在已经有一套按 Diátaxis 组织的文档站点脚手架。
