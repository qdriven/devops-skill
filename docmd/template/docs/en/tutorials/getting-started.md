# Getting started with the template

By the end of this tutorial you will have a local docmd site running from this template, and you will know where each Diátaxis folder belongs.

## Prerequisites

- Node.js 18+
- npm

## Steps

1. Open a terminal in this template directory (`docmd/template`, or your copied target directory).
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` and confirm the Home page lists Tutorials, How-to, Explanation, and Reference.
5. Open `docs/tutorials/` and notice this page lives under Tutorials — learning-oriented content.

You now have a working documentation site scaffolded with Diátaxis folders.
